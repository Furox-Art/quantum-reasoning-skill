# Getting Started  
  
## The problem  
  
Ask a hard question and most AI assistants pick the first reasonable-sounding answer and defend it. That is not thinking. That is pattern matching with confidence.  
  
## The fix  
  
This skill makes the AI hold multiple competing answers at once, attack each one with evidence, and only settle when one genuinely wins.  
  
## Usage  
  
Just invoke the skill by name when facing a hard problem:  
  
```  
quantum-reasoning: should we migrate our monolith to microservices?  
```  
  
## What you get  
  
- Multiple genuinely different approaches explored  
- Each one tested against evidence, not vibes  
- Weak paths killed, strong paths verified  
- A final answer with honest uncertainty stated  
  
## When NOT to use it  
  
Simple questions. If the answer is obvious, do not waste compute on branching.
